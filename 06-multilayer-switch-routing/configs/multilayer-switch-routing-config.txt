# Lab 06 — Multilayer Switch Inter-VLAN Routing

## Configuration Record

## 1. Configuration Purpose

This file records the configuration used to turn `MLS1` from a Layer 2 access switch into a multilayer switch capable of routing between VLANs.

The final design contains:

```text
VLAN 10 → USERS       → 192.168.10.0/24 → Gateway 192.168.10.1
VLAN 20 → FINANCE     → 192.168.20.0/24 → Gateway 192.168.20.1
VLAN 30 → IT          → 192.168.30.0/24 → Gateway 192.168.30.1
```

The key Layer 3 components are:

```text
SVI Vlan10
SVI Vlan20
SVI Vlan30
ip routing
```

---

# 2. Device

```text
Hostname: MLS1
Platform: Cisco 3560 Multilayer Switch
```

The switch performs both:

```text
Layer 2 switching
+
Layer 3 routing
```

# 3. VLAN Configuration

The following VLANs were created:

```cisco
enable
configure terminal

vlan 10
 name USERS

vlan 20
 name FINANCE

vlan 30
 name IT

end
```

## Purpose

The VLANs create three separate Layer 2 broadcast domains.

```text
VLAN 10 → USERS
VLAN 20 → FINANCE
VLAN 30 → IT
```

# 5. Layer 3 Routing Enablement

The multilayer switch was enabled for Layer 3 routing using:

```cisco
ip routing
```

This is a global configuration command.

## Purpose

Without `ip routing`:

```text
VLANs
   ↓
SVIs
   ↓
Layer 3 interfaces exist
```

but the switch does not route traffic between those interfaces.

With:

```cisco
ip routing
```

MLS1 can perform:

```text
VLAN 10
   ↓
SVI 10
   ↓
Routing table
   ↓
SVI 20
   ↓
VLAN 20
```

and similarly for VLAN 30.

---

# 9. Complete Layer 3 Configuration

The core Layer 3 portion of the configuration is:

```cisco
ip routing

interface Vlan10
 description SVI for VLAN 10 - USERS
 ip address 192.168.10.1 255.255.255.0
 no shutdown

interface Vlan20
 description SVI for VLAN 20 - FINANCE
 ip address 192.168.20.1 255.255.255.0
 no shutdown

interface Vlan30
 description SVI for VLAN 30 - IT
 ip address 192.168.30.1 255.255.255.0
 no shutdown
```

This combination provides:

```text
3 VLANs
+
3 SVIs
+
3 Layer 3 gateways
+
IP routing
```

# 11. Interface Relationships

The final logical relationships are:

```text
Fa0/1 → VLAN 10 → SVI Vlan10 → 192.168.10.1
Fa0/2 → VLAN 10 → SVI Vlan10 → 192.168.10.1

Fa0/3 → VLAN 20 → SVI Vlan20 → 192.168.20.1
Fa0/4 → VLAN 20 → SVI Vlan20 → 192.168.20.1

Fa0/5 → VLAN 30 → SVI Vlan30 → 192.168.30.1
Fa0/6 → VLAN 30 → SVI Vlan30 → 192.168.30.1
```

This demonstrates that multiple physical access ports can share one logical Layer 3 gateway because they belong to the same VLAN.

# 17. Configuration Logic

The final configuration can be understood as a chain:

```text
Physical access port
        ↓
VLAN membership
        ↓
SVI gateway
        ↓
IP routing
        ↓
Routing table
        ↓
Destination VLAN
        ↓
Layer 2 forwarding
```

For example:

```text
PC0
192.168.10.10
   ↓
Fa0/1
   ↓
VLAN 10
   ↓
SVI 10
192.168.10.1
   ↓
IP ROUTING
   ↓
SVI 20
192.168.20.1
   ↓
VLAN 20
   ↓
PC2
192.168.20.10
```

---

# 18. Important Distinction From Router-on-a-Stick

Lab 05 used:

```text
Router subinterfaces
```

Example:

```text
G0/0.10
G0/0.20
```

Lab 06 uses:

```text
SVIs
```

Example:

```text
Vlan10
Vlan20
Vlan30
```

Therefore:

```text
Router-on-a-Stick:
External router performs routing

Multilayer switch:
The switch itself performs routing
```

- Three SVIs
