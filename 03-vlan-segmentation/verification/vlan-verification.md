## Broadcast Isolation

An ARP broadcast generated by PC0 in VLAN 10 was observed only within VLAN 10. PC2 and PC3, which belong to VLAN 20, did not receive the broadcast.

## Conclusion

The switch successfully separates the USERS and FINANCE networks into independent Layer 2 broadcast domains. Hosts within the same VLAN can communicate, while communication between VLANs fails because no Layer 3 inter-VLAN routing has been configured.
